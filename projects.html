LUCKY FRUIT
PLATFORM: Windows  —  LANG: C#  —  FRAMEWORK: .NET / WinForms
COMPLETE
1 / 3

A three-reel slot machine game built entirely from scratch in C#. Players match symbols across three independently spun reels, with win probability calculated by multiplying each reel's symbol probability together — for example, P(Cherry, Cherry, Cherry) = (7/20) × (7/20) × (7/20) = 0.042875. The game targets a total RTP of 92.81%, with a regulatory par sheet exportable as a CSV showing full probability and statistics for the slot.

What I Built
  • Reel strip design — weighted symbol counts tuned to a target RTP of 92.81%, calculated using combinatorial probability without simulation
  • Math engine — computes exact prize probabilities and expected values per symbol
  • Par sheet export — generates a regulatory CSV report of probabilities and statistics
  • WinForms UI — playable interface with spin animation and credit balance tracking
Project Structure
  • Data/ReelDefinitions.cs — strip definitions and RTP design table
  • Engine/MathEngine.cs — theoretical RTP calculation
  • Engine/SpinEngine.cs — random spin and result evaluation
  • Models/ — Symbol, PayTable, ReelStrip
  • Reports/ParSheetGenerator.cs — CSV par sheet export
  • UI/ — WinForms UI and animation

A modular third-person shooter framework built in Unity 6, aimed at creating an authentic, cinematic TPS template. The project features 8-directional locomotion, Cinemachine-driven camera controls, a runtime weapon equipment system with Animation Rigging IK, scene persistence, and an inventory system — all built on a scalable, component-based architecture.

What's In So Far
  • Locomotion & combat — 8-directional movement, sprinting, aiming, and animation-driven combat using Unity's New Input System
  • Cinemachine camera system — free-look movement, dynamic follow behavior, and aim-down-sights functionality
  • Weapon equipment system — runtime weapon swapping, multiple equipment slots, and Animation Rigging IK for realistic weapon handling
  • Scene persistence & inventory — systems for retaining player state and items across scenes

  • Exploring expansion for multiplayer compatibility
